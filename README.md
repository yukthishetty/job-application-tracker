# 💼 Full-Stack Job Application Tracker

A full-stack web application designed to help students and job seekers organize, track, and manage their job and internship applications in one place.

## 📌 Project Overview

Managing multiple job and internship applications can become difficult when application details, interview dates, deadlines, and status updates are spread across different platforms.

The Job Application Tracker aims to provide a centralized dashboard where users can record applications, monitor their progress, track interviews, and keep important application information organized.

## 🎯 Objectives

- Centralize job and internship application tracking
- Monitor application progress and status
- Keep company and job-role information organized
- Track interviews and application deadlines
- Provide a clear dashboard for application insights
- Reduce the chances of missing important follow-ups

## 🚀 Planned Features

- Add and manage job applications
- Track company and job role
- Application status tracking
- Interview tracking
- Deadline and follow-up tracking
- Search and filter applications
- Dashboard with application statistics
- Edit and delete application records
- User authentication
- Responsive user interface
